Speedy

Media & file downloader

Connect to your Speedy server

Speedy downloads files to the computer running the server. Enter that computer's address below.

How do I start the server?
  1. On your computer, open a terminal in the Speedy folder.
  2. Run:
    python speedy_web.py --host 0.0.0.0 --port 8000
  3. Find the computer's local IP address: ipconfig on Windows, ifconfig on macOS or Linux.
  4. Enter it above, e.g. http://192.168.1.5:8000.

Both devices must be on the same Wi-Fi network. Binding to 0.0.0.0 exposes the server to that network and it has no password, so only do this on a network you trust.
